##  Featured Project

### Hazir - AI Powered Service Marketplace App

Hazir is a mobile service marketplace app that connects customers with verified local service providers. The app includes booking, service listings, provider dashboards, real-time messaging, live tracking, ratings, reviews, and AI-powered service recommendations.

**Main Features:**

- User authentication
- Service seeker dashboard
- Provider dashboard
- Service search and filtering
- Booking and scheduling system
- Real-time messaging
- Notifications
- Ratings and reviews
- AI-based service recommendations
- Firebase backend integration

**Tech Used:**

Flutter, Dart, Firebase Authentication, Cloud Firestore, Firebase Storage, Firebase Cloud Messaging, Google Maps SDK, Android Studio

🔗 Repository: [Hazir Service Marketplace](https://github.com/Pasha806/hazir-service-marketplace)
